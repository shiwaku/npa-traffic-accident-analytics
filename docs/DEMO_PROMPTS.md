# 発表デモの質問セット

10/22 MIERUNE JCT in TOKYO（持ち時間20分）のライブデモで、claude.ai に打つ質問。
[ANALYSIS_PROMPTS.md](ANALYSIS_PROMPTS.md) から選び、**ひとつの会話で、問いが前の答えを受けて深まる**順に並べた。

[VERIFY_PROMPTS.md](VERIFY_PROMPTS.md) の11問は動作確認用で、ビューの描画とガードレールを1問ずつ確かめる。
こちらは「人が問いを立て、AI が数えて描き、人が確かめる」流れを見せるためのもの。

数字は 2026-10-12 時点の実測値（データは2019〜2025年）。生活道路はすべて
**5.5m未満の道と、5.5m未満どうしの交差点**で数える。

---

## 流れ

| | 見せること | 問い | 返ってくるもの |
|---|---|---|---|
| 1 | 全体 | 生活道路は減っているか | グラフ（ダッシュボード） |
| 2 | 誰が・いつ | 若い歩行者・自転車は何時に多いか | 表 |
| 3 | どこで | その事故は駅のまわりのどこで起きたか | 地図 |
| 4 | できないこと | 小学生だけでは？ | 「出せない」と答える |
| 5 | 確かめる | 使った SQL は？ | SQL |

1〜3 で「聞くだけで表・グラフ・地図が返る」、4〜5 で「前提を守り、確かめられる」を見せる。
4 と 5 は発表の結論（**人は、問いを立て、確かめる**）につなげる。

---

## 1. 全体

```
生活道路の事故件数の推移を、全事故と比べてダッシュボードで見せて。2019年を100とした指数で。
```

**「ダッシュボードで見せて」を必ず入れる。** 2026-10-20 に claude.ai（無料プラン）で試したところ、
入れないと AI は seikatsu_dashboard を呼ばず、run_sql で SQL を3回書いて claude.ai 側のグラフで答えた
（数字は同じだが、ダッシュボードは出ない）。入れると seikatsu_dashboard が呼ばれた。

ダッシュボードが出る。2025年の指数は**生活道路 67・全事故 75**。生活道路のほうが速く減っている。

見せどころ: 生活道路を「5.5m未満の道と、5.5m未満どうしの交差点」で数えたと AI が断ること。
2020年はコロナ禍で全体が19%減っており、指数で比べる理由になる。

## 2. 誰が・いつ

```
2025年、生活道路で0〜24歳の歩行者・自転車が関わった事故を、発生した時間帯別に。
```

8,297件のうち **8時台 1,140件・7時台 964件・17時台 945件・16時台 884件**。登下校の時間に山がある。

見せどころ: 年齢と種別を**同じ当事者**で判定していること（「A が若者で B が歩行者」のような混同をしない）。

## 3. どこで

```
新宿駅から半径1kmで、2019〜2025年のその事故を地図に出して。
```

地図が出る。中心 35.6896, 139.7006 なら **36件**（中心座標の取り方で前後する）。
「その事故」で2の条件（生活道路・0〜24歳の歩行者・自転車）が引き継がれることも見せる。

2 を飛ばしてスライドの言い方（「新宿駅から半径1kmで、若い歩行者・自転車が関わった7年分の事故を地図に出して」）で
聞くと、2026-10-20 の試行では AI が生活道路で絞らずに呼び、**156件**が出た。そのときは地図の上の
「5.5m未満の道と、5.5m未満どうしの交差点」を押すと36件になる。このボタンは AI を通さずサーバーを呼び直す
（スライド13枚目「画面のボタンは AI を通さない」をその場で見せられる）。

見せどころ: 点を押すと事故の中身が出る。「死亡事故のみ」を押すと0件になり、そう表示される
（7年間・半径1kmで若者の死亡事故は無い）。

## 4. できないこと

```
この中で、小学生だけだと何件？
```

**数字を出さずに「出せない」と答えるのが正しい。** 年齢は年齢層コードで、最小区分が0〜24歳。
小学生・高校生・大学生・若手社会人が同じ箱に入る。

見せどころ: AI がそれらしい数字を作らないのは、前提（CLAUDE.md とサーバーの説明）に書いてあるから。
その前提も AI が数えて確かめながら書いた、という次の話につなぐ。

## 5. 確かめる

```
いまの集計に使ったSQLを見せて。
```

2 や 3 の SQL が出る。`"年齢（当事者A）"='0～24歳' AND "当事者種別（当事者A）" IN (...)` の
OR で、同じ当事者で判定しているのが読める。

見せどころ: 数字の出どころをその場で確かめられる。まとめスライドの「確かめる」は人の役割として残っている。
