# 発表会で触ってみる（来場者向け）

警察庁の交通事故統計（2019〜2025年、約218万件）を、claude.ai から日本語で集計・地図化できます。
このページの URL を claude.ai の「コネクタ」に登録するだけで使えます。

**使えるのは 2026-10-22 23:59（日本時間）まで。** それ以降は自動で止まります。

---

## 1. 使える条件

| アカウント | 使えるか |
|---|---|
| 無料プラン（個人） | ○ カスタムコネクタは **1つまで**。2026-10-10 にグラフ・地図まで出ることを確認済み |
| Pro / Max（個人） | ○ |
| Team / Enterprise（会社） | **Owner しか追加できない。** 個人アカウントで試すか、下の「追加できないとき」へ |

（2026-10 時点。条件は [Anthropic のヘルプ](https://support.claude.com/en/articles/11175166-getting-started-with-connectors-on-claude-ai) に従う）

## 2. 追加のしかた

1. claude.ai を開き、**設定 → コネクタ**（Settings → Connectors）
2. **カスタムコネクタを追加**（Add custom connector）
3. 名前は自由（例: `交通事故統計`）。URL に次を貼る

   ```
   https://npa-traffic-accident-mcp.shi-works-worker.workers.dev/e/HEh8-uaLCZxneNDUsleTKA/mcp
   ```

4. **追加**（Add）。認証の設定（Advanced settings）は空のままでよい
5. 新しいチャットで入力欄の **＋ → コネクタ** から、いま追加したものを**オン**にする

> **URL をブラウザで開かないこと。** `Missing session ID` と出るが、壊れているわけではない。
> claude.ai のコネクタに貼る専用の URL です。

> 最初の1問だけ、**返事まで数十秒かかる**ことがある（サーバーが寝ていて起きるまでの時間）。

## 3. 最初に聞いてみる

そのままコピーして貼ってください。グラフや地図が会話の中に出ます。

```
生活道路の事故件数の推移を、全事故と比べて。2019年を100とした指数で。
```

```
新宿駅から半径1kmの2025年の生活道路の事故を地図に出して。
```

```
[自分の県]の生活道路の事故の推移を、全国と比べて。全事故に占める割合も。
```

```
2025年、生活道路で0〜24歳の歩行者・自転車が関わった事故を、発生した時間帯別に。
```

ほかの聞き方は [ANALYSIS_PROMPTS.md](ANALYSIS_PROMPTS.md)（実務の問いと、答えの目安の数字）。

**聞き方のコツ**

- 「生活道路」は数え方が2通りあり、件数が約1.8倍変わる。Claude がどちらで数えたか書くので確かめる
- 実数だけでなく「全事故と比べて」「割合も」と頼むと傾向を読み誤りにくい
- 「使った SQL も見せて」と頼むと、数字の出どころを確かめられる

**このデータで答えられないこと**: 年齢は「0〜24歳」が最小の区分なので「10代」「小学生」だけは数えられない。
物損事故は入っていない（人身事故のみ）。

## 4. 追加できないとき

- **会社アカウントで「カスタムコネクタを追加」が無い** → 個人アカウント（無料で可）でログインし直す
- **アカウントを持っていない・作りたくない** → 隣の人の画面で一緒に触る。発表者の画面でも質問を受けて実演します
- **無料プランで、すでに別のカスタムコネクタを登録している** → 1つまでなので、一時的にどちらかを外す

## 5. 終わったら

10/22 を過ぎるとつながらなくなるので、**設定 → コネクタ から削除**してください
（無料プランは1つ枠を空けておけます）。
