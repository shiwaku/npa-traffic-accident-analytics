# 誰が、何に使えるか

この仕組みを使えそうな人ごとに、実際の業務で事故データがどう使われているか、
この仕組みで答えられる問い・答えられない問いを整理した。
後半では、交通事故総合分析センター（ITARDA）が公開している分析事例を、
この仕組みで再現できるかで分けた。

調べたのは 2026-10-10 時点の公開資料。出典は各節に書いた。
「確認できなかったこと」は推測で埋めずに、そのまま残している。

---

## 背景：自治体の多くは事故の場所を把握していない

総務省「生活道路における交通安全対策に関する政策評価」（令和7年6月）
<https://www.soumu.go.jp/main_content/001017710.pdf>

生活道路の事故が多い市区町村を選んで調べたもので、回答は413市区町村。
全国の平均ではない。

| 項目 | 割合 |
|---|---:|
| 事故の発生箇所を「おおむね把握している」 | 20.6% |
| 事故の発生箇所を「ほとんど把握していない」 | 22.3% |
| オープンデータで自ら把握している | 6.9% |
| 対策箇所の優先順位に、事故実績を「ほとんど参考にしていない」 | 44.6% |

自治体からは「オープンデータの使い方が分からない」「地図化する余裕やスキルがない」
という声が挙がっている。

これを受けて、国交省と警察庁が
「オープンデータを用いた交通事故発生箇所の地図化マニュアル」（令和7年7月）を出した。
Excel で緯度経度を変換し、地理院地図に貼る手順である。
<https://www.mlit.go.jp/road/road/traffic/sesaku/pdf/chizuka_manual.pdf>

この仕組みは、その手順を「話しかけるだけ」にしたものと位置づけられる。

### 2026年9月1日からの生活道路30km/h

対象は「中央線等のない道路」で、警察庁は主に幅員5.5m未満を想定している。
<https://www.npa.go.jp/bureau/traffic/seikatsudouro/seikatsudoro.html>

- **答えられる**：施行前のベースライン（2019〜2025年の生活道路の事故件数、人対車両、
  時間帯、月ごとの季節性）。2026年分が公開されれば、施行前後の比較もできる。
  その場合は「事故が起きた月」で切る必要がある
- **答えられない**：対象道路そのもの（中央線の有無の列が無い）、速度の遵守状況、
  重傷の増減、法改正による因果効果

## ITARDA の公開分析事例との対応

### ITARDA の集計と1件単位で一致した

ITARDA は有償でデータを提供しているが、分析結果の一部はイタルダ・インフォメーションとして無料で公開している。
その公開資料に載っている数字と、同じ条件で数えた値を比べた。

| ITARDA の数字 | ITARDA | この仕組み | 条件 |
|---|---:|---:|---|
| Info No.150「身近な道路」の事故（2024） | 30,870 | 30,870 | 路線名が市町村道 × 地形が市街地 × 5.5m未満の道と5.5m未満どうしの交差点 |
| 同・自転車が関わる事故（2024） | 13,150 | 13,150 | 上の条件で、当事者A か B が自転車 |
| WEB版#04 市町村道の事故（2025） | 128,591 | 128,591 | 路線名が市町村道 |
| 同・市町村道・市街地・単路（2025） | 34,815 | 34,815 | 上に、地形が市街地 × 道路形状が単路 |
| WEB版#03 高齢歩行者の死者（2024） | 650 | 650 | 当事者A・B のうち、65歳以上の歩行者で死亡した人 |

年はいずれも統計に計上された年。照合に使った SQL：

```sql
WITH b AS (SELECT * FROM honhyo
           WHERE "路線名" LIKE '%市町村道%'
             AND "地形" IN ('市街地－人口集中','市街地－その他'))
SELECT count(*) FROM b
WHERE "資料年次" = 2024
  AND "車道幅員" IN ('単路－3.5m未満','単路－3.5m以上','交差点－小（5.5m未満）－小');
-- 30,870
```

No.150 と一致したことから、ITARDA は5.5m未満の交差点を
「交わる2本とも5.5m未満」で数えていると考えられる（推測）。
ただし No.150 の「自転車が第1当事者の割合17%」は再現できなかった
（この仕組みでは 3,958件、12.8%）。自転車の範囲が違うためと推測している。

### 専門家向けのまとめ

**強い分析**
- 道路の条件を組み合わせた件数・構成比・経年の指数。路線名（道路種別）、地形、
  車道幅員、信号、一時停止、速度規制、歩車道区分が使える
- 当事者A（第1当事者）と当事者B（第2当事者）の組み合わせ
- 緯度経度を使った箇所の抽出と、半径を決めた前後比較
- ITARDA が公開している集計と合うので、全国の傾向を自分の地域・箇所まで掘り下げる使い方

**弱い分析（データに項目が無い）**
- 細かい事故の型。`事故類型` は「人対車両・車両相互・車両単独・列車」の4区分だけで、
  出会い頭・追突・右直・横断中が取り出せない。ITARDA の分析の多くはここを使う
- 重傷と軽傷の区別。`人身損傷程度` は死亡・負傷だけで、死亡重傷率が出せない
- 人的要因・法令違反
- 実年齢（子ども・学齢）。年齢は層で、最小区分が0〜24歳
- 保有台数・交通量・人口あたりの率
- 物損事故

**足せば広がるデータ**（効果の大きい順）
1. 国勢調査の町丁目境界と人口：面積あたり・人口あたりの多発エリア抽出ができる（#59）
2. 道路交通センサスの交通量：幹線道路の事故率が出せる
3. 市区町村コードと名称の対応表：市区町村名で聞ける
4. ゾーン30の区域と指定時期：前後比較の範囲を正確に決められる（因果は依然として言えない）
