# 分析プロンプト集

交通安全計画・通学路点検・施策の検討など、実務で出てくる問いをそのまま聞ける形にしたもの。
claude.ai / Claude Desktop / Claude Code でこのサーバーを有効にして、コピーして使う。
`[ ]` の部分は自分の地域や条件に置き換える。

各問いに付けた数字は 2026-10-02 時点の実測値（データは2019〜2025年）。
生活道路は特に断りがなければ **5.5m未満の道と、5.5m未満どうしの交差点**で数えている。答えが合っているかの目安にする。

動作確認（ビューが出るか・ガードレールが効くか）は [VERIFY_PROMPTS.md](VERIFY_PROMPTS.md)。

---

## 聞き方のコツ

| | 例 | なぜ |
|---|---|---|
| **生活道路の定義を先に言う** | 「5.5m未満どうしの交差点だけで」「5.5m未満の道が1本以上交わる交差点も含めて」 | 件数が約1.8倍変わる。言わなければ前者で数え、そう注記される |
| **母数と比べてもらう** | 「全事故と比べて」「構成比も」 | 2020年はコロナ禍で全体が19%減った。実数の増減だけでは傾向を読み誤る |
| **地域・期間を絞る** | 「千葉県の」「2025年の」 | 全国・7年だと自分の地域の話にならない |
| **年は統計に計上された年のまま** | 何も言わない | 警察庁の公表値と一致する。年末に起きた事故の一部は翌年の統計に計上される。月別・季節性を見るときだけ「事故が起きた年で」と言う |
| **SQL を見せてもらう** | 「使ったSQLも」 | 数字の出どころをその場で確かめられる |

## 1. 概況をつかむ

### 1-1. 生活道路の事故は全体より速く減っているか

```
生活道路の事故件数の推移を、全事故と比べて。2019年を100とした指数で。
```

ダッシュボードが出る。2019→2025年で生活道路は **65,188 → 43,673件（指数 67）**、
全事故は **381,237 → 287,023件（指数 75）**。生活道路のほうが速く減っており、
全事故に占める割合も 17.1% → 15.2% に下がっている。

### 1-2. 自分の県の位置づけ

```
[千葉県]の生活道路の事故の推移を、全国と比べて。全事故に占める割合も。
```

県だけの数字を見ても多いか少ないか判断できない。全国の割合（2025年 15.2%）と並べて読む。

> **県同士の比較には注意。** 2025年の生活道路の割合は東京 29.0% に対し、山形 3.7%・北海道 4.3%・
> 福井 4.8% と極端に差がある。道路事情だけでは説明しにくく、**県によって車道幅員の記録の仕方が
> 違う可能性**がある。このデータからは判別できないので、県の順位をそのまま結論にしない。
> 自県の推移を見るぶんには、記録の仕方が年によって変わらない限り影響は小さい。

### 1-3. 県内のどこで多いか

```
[千葉県]で、2025年に生活道路の事故が多い警察署を上位10署。
```

2025年の千葉県は **柏 182件・市川 166件・船橋 145件・松戸 140件・千葉北 125件** の順。
市区町村名は入っていないので、名前で見るなら**警察署別**が手早い。
市区町村で見たいときは「市区町村コード別に」と頼む。コードは都道府県を除いた3桁
（柏市なら `217`）なので、全国地方公共団体コードの表と突き合わせて名前を付ける。

### 1-4. 市街地と郊外

```
生活道路の事故を地形（人口集中地区・その他市街地・非市街地）別に。全事故に占める割合も。
```

7年間で、生活道路の割合は人口集中地区 17.4%・その他の市街地 15.3%・非市街地 15.0%。

## 2. 対象者で絞る

### 2-1. 高齢運転者

```
75歳以上が第1当事者（当事者A）の事故の推移と、全事故に占める割合。
```

**27,673件（7.3%）→ 30,088件（10.5%）**。全事故が減るなかで件数も割合も増えている。

> 当事者Aは「過失が最も重い側」。75歳以上が**運転していた**とは限らない（歩行者・自転車も含む）。
> 運転者に限るなら「当事者種別が自動車・二輪車の」と付け足す。

### 2-2. 通学時間帯のこども・若者

```
2025年、生活道路で0〜24歳の歩行者・自転車が関わった事故を、発生した時間帯別に。
```

8,297件のうち、**8時台 1,140件・7時台 964件・17時台 945件・16時台 884件**。登下校の時間に山がある。

> 年齢は年齢層コードで、0〜24歳が最小区分。**「小学生」「高校生」だけは取り出せない。**
> 通学時間帯に絞ると通学中の事故に近づくが、通学中かどうか自体は記録されていない。

### 2-3. 高齢歩行者の夜間事故

```
生活道路で、65歳以上の歩行者が死傷した事故を昼夜別に。死亡事故の件数と割合も。
```

7年間で、昼 11,271件（死亡 248件・2.2%）、夜 4,435件（死亡 205件・4.6%）。
**件数は昼が多いが、夜は死亡事故になる割合が約2倍。**

> 年齢と種別と損傷程度は**同じ当事者**で判定される（A が65歳以上で、B が歩行者、のような混同はしない）。

### 2-4. 自転車

```
生活道路の事故に関わった自転車のうち、第1当事者（当事者A）と判定された割合の推移。
```

18.3%（2019）→ 21.8%（2021）→ **26.6%（2022）** → 28.2%（2024）→ 29.2%（2025）。

> **2021→2022年に段差がある。** 事故の実態が変わったのか、過失の認定の運用が変わったのかは
> このデータからは判別できない。A/B 別の推移を資料に載せるときは必ずこの注記を付ける。

### 2-5. 電動キックボード（特定小型原付）

```
2025年の特定小型原付自転車が関わった事故の件数と、第1当事者だった割合。
```

**386件、うち206件（53%）で第1当事者。** 2024年は338件・211件（62%）。区分ができたのが2024年で
2年分しかなく、件数も少ないので推移としては読めない。
自転車の集計には含まれない（別区分）。

## 3. 道路環境で絞る

### 3-1. 信号のない生活道路の交差点

```
2025年、交わる2本とも5.5m未満の交差点での事故のうち、信号機がないものの割合。
さらにそのうち一時停止の標識があったものの割合。
```

21,050件のうち **信号機なし 19,253件（91%）**。そのうち一時停止の標識があったのは 8,713件（45%）。

### 3-2. 歩道のない生活道路での歩行者事故

```
生活道路の人対車両事故のうち、歩車道区分なしの道路で起きたものの件数と割合の推移。
```

2025年は 8,056件のうち 2,933件（36%）。2019年は 9,123件のうち 3,614件（40%）。

### 3-3. 速度規制

```
2025年の生活道路の事故を、第1当事者側の道路の指定速度規制別に。
```

指定なし（法定速度）18,071件・30km/h以下 8,978件・40km/h以下 6,787件 ほか。

> 「指定のみ」なので、**規制が指定されていない道路は「指定の速度規制なし等」**に入る。
> 生活道路の多くはここに入り、実際の制限速度は分からない。
> ゾーン30の区域内かどうかは別の項目（ゾーン規制）で見る。

### 3-4. 学校や駅の周辺

```
緯度 [35.xxxx]、経度 [139.xxxx] から半径500mで、2019〜2025年の生活道路の事故を地図に。
0〜24歳の歩行者・自転車が関わったものに絞って。
```

地図が出る（Claude Desktop・claude.ai）。**地名から座標は引けない**ので、緯度経度を渡す。
点が5,000件を超えると間引かれるので、件数は地図の点ではなく返ってきた「該当」件数で読む。

## 4. 時期・時間帯を見る

### 4-1. 季節性

```
事故が起きた年で、2019〜2024年の事故を月別に。
```

**12月が最多（181,034件）、5月が最少（143,797件）。** 10〜12月が高い。

> 月別を見るときだけ事故が起きた年で数える。2025年に起きた事故の一部（約3%）は2026年の統計に
> 計上されるため、まだデータに無い。ここでは2024年までにしている。

### 4-2. 平日と休日で時間帯の山が違うか

```
2025年の事故を、平日と休日（土日・祝日）に分けて、多い時間帯の上位3つ。
```

平日は **8時台・17時台・7時台**（通勤・通学）、休日は **17時台・10時台・11時台**。

### 4-3. 薄暮時の歩行者事故

```
事故が起きた年で2019〜2024年、薄暮時間帯（昼夜区分が「暮」）の人対車両事故を月別に。
```

**11月 5,142件・12月 4,988件・10月 4,596件**。日没が早まる時期に集中する。

## 5. 施策の検討材料

### 5-1. ゾーン30

```
ゾーン30の区域内で起きた事故の件数の推移。生活道路の事故と比べて。
```

2019年 3,896件 → 2025年 3,871件。

> **ゾーン30の効果は判定できない。** 区域の指定自体が年々増えているため、件数の増減は
> 区域が広がった分を含む。区域の面積や指定時期はこのデータに無い。
> なお7年間でゾーン30内の事故 25,332件のうち、生活道路（5.5m未満の道と、5.5m未満どうしの交差点）上は 9,330件（37%）だけ。
> 区域内にも5.5m以上の道路がある。ゾーン30プラス（ハンプ等）は区別できない。

### 5-2. 生活道路と幹線道路の重さの違い

```
生活道路と車道幅員5.5m以上の道路で、死亡事故の割合を比べて。7年間の合計で。
```

生活道路（5.5m未満の道と、5.5m未満どうしの交差点）0.67%（355,708件中 2,378件）、5.5m以上の道路 0.96%（1,437,197件中 13,789件）。
片側だけ5.5m未満の交差点は 0.72%。

> 死亡事故は7年間で18,761件しかない。県や年でさらに絞ると年に数件になり、
> 割合の差は偶然の範囲に入る。小さい母数で比べるときは件数も一緒に示してもらう。

### 5-3. 資料用の1枚

```
[千葉県]の生活道路の事故について、交通安全計画の資料に載せる1枚をまとめて。
推移（全事故との比較）、若年の歩行者・自転車、高齢者、ゾーン30、読むときの注意を入れて。
```

ダッシュボードと集計を組み合わせてまとめてくれる。**注意書き（定義・母数・判別できないこと）
まで資料に残す**よう頼むと、あとで数字だけが独り歩きしない。

## このデータでは答えられない問い

聞いても、それらしい数字を出さずに「できない」と答えるのが正しい。

| 問い | できない理由 | 代わりにできること |
|---|---|---|
| 10代・小学生・20代の事故 | 年齢は年齢層コードで、最小区分が0〜24歳 | 0〜24歳で見る。通学時間帯で絞る |
| 物損事故 | 本票は人身事故のみ | — |
| 重傷と軽傷の内訳 | 損傷程度は「死亡」「負傷」「損傷なし」まで | 死亡事故の割合で見る |
| 出会い頭・追突など事故の型 | 事故類型は「人対車両」「車両相互」「車両単独」「列車」の4区分のみ | 道路形状（交差点・単路）と組み合わせる |
| 信号無視・スマホなど原因 | 法令違反・事故要因の項目が無い | — |
| 人口あたり・交通量あたりの事故率 | 人口・交通量・道路延長が無い | 全事故に占める割合で比べる。外部の統計と組み合わせる |
| 市区町村名での集計 | 市区町村コード（3桁）はあるが名称が無い | 警察署別で見る。コード別に出して、全国地方公共団体コードと突き合わせる |
| ゾーン30の効果 | 区域の指定時期・面積が無い。相関しか見えない | 件数の推移を、区域拡大の注記付きで見る |
